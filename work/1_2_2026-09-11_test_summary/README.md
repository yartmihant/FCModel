# Сводная таблица проверок корпуса

Результат: `../1_2_2026-09-11_test_summary.csv`. Одна строка на каждый из 1130 текущих файлов, 50 столбцов; сортировка по имени. Первые 33 столбца содержат прежние roundtrip/Fidesys результаты, ещё 17 — аудит по спецификации (методика: `../1_2_2026-09-11_spec_audit/README.md`). Формат — CSV с запятой, UTF-8 с BOM, окончания записей CRLF. Кавычки и переносы строк внутри значений экранированы по правилам CSV.

## Источники и актуальность

- Roundtrip: `work/1_2_2026-09-11_json_cleanup/roundtrip_results.json`.
- Fidesys: `work/1_2_2026-09-11_fidesys_import/results.json`; для двух исправленных JSON применены новые результаты из `work/1_2_2026-09-11_json_cleanup/fidesys/results.json`.
- Последовательные повторы двух незавершённых импортов: `work/1_2_2026-09-11_fidesys_retry/results.json`.

Таблица объединяет существующие проверки, не запускает их заново. SHA-256 каждого текущего исходника совпал с обеими используемыми записями. Удалённый оборванный файл исключён. Пути в CSV отсчитываются от корня проекта; время окончания относится к соответствующему прогону, а не отдельному файлу.

## Значение результатов

Roundtrip: 453 совпадения, 611 расхождений JSON, 66 ошибок загрузки модели. Успех означает равенство после load/save по строгому компаратору; порядок ключей объектов и лексическое оформление JSON не учитываются. Типы значений, порядок массивов и наличие полей учитываются.

Fidesys: 450 импортов без ошибок (288 без предупреждений, 162 с предупреждениями), 678 импортов с ошибками, 2 без подтверждения завершения. Успех подтверждён контрольным маркером и нулевым счётчиком ошибок API. Это проверка импорта препроцессором, не решателем и не проверка сохранения всех полей. Код завершения launcher сам по себе не определяет успех.

Для незавершённых импортов неизвестные счётчики ошибок API, уникальных ошибок, узлов и элементов оставлены пустыми. Ноль означает измеренное нулевое значение. Предупреждения и ошибки представлены отдельно. Списки сообщений соединены через ` | `; полные журналы указаны в отдельных столбцах. Счётчик ошибок API может отличаться от числа уникальных сообщений.

Для ошибок загрузки библиотеки указаны этап, исключение, текст и место возникновения. Для завершившихся roundtrip указаны число и виды расхождений, JSON-пути и полный список записей различий из реестра. Длинные значения в исходном реестре представлены сокращённо с длиной и хешем; таблица сохраняет это представление без дополнительного сокращения.

Оба теста пройдены у 179 файлов. У 6 файлов библиотека падает при загрузке, хотя Fidesys импортирует без ошибок; ещё у 265 Fidesys импортирует без ошибок, но roundtrip обнаруживает различия.

## Проверки и сборка

`build.mjs` формирует таблицу через Artifact Tool, проверяет данные и сохраняет CSV и визуальный образец первых строк `preview.png`. Для повторного запуска нужен Node.js и доступный пакет `@oai/artifact-tool` через `node_modules`; корень проекта задан в скрипте.

`verification.json` содержит результаты текущей сборки. `independent_verification.json` относится к исходным 33 столбцам. Проверка расширенной таблицы находится в `../1_2_2026-09-11_spec_audit/csv_verification.json`: сверены все 50 столбцов, сохранность прежних значений и полный перенос находок. Максимальный размер ячейки — 15949 символов. Визуальные образцы просмотрены: имена, статусы и новые столбцы читаются без обрезки.
