# Сводная таблица проверок корпуса

Результат: `../1_2_2026-09-11_test_summary.csv`. После перехода на Fidesys roundtrip — 1130 строк, 45 столбцов, сортировка по имени. Формат: CSV, запятая, UTF-8 с BOM. Оформление PNG-предпросмотра не является свойством CSV.

## Результаты

- Roundtrip: 453 совпадения, 611 расхождений JSON, 66 ошибок загрузки. Игнорируется порядок ключей объектов и лексическое оформление JSON; остальные различия сохраняются.
- Fidesys: 450 успешных циклов импорта и экспорта, 678 ошибок импорта, 2 без подтверждения импорта. У всех 450 живых моделей выходной JSON отличается от исходного. Полный цикл и равенство JSON — независимые результаты; решатель не запускался.
- Спецификация: 491 файл с нарушениями; 454 только с legacy/неясностями; 185 без находок по выполненным правилам. Всего 780 violation, 172 legacy, 4634 ambiguity. Это не полная проверка физической корректности.
- Размеры сетки: 1097 совпадений, 31 расхождение, 2 неизвестных результата. Все 31 расхождение относятся к импортам с ошибкой.

## Столбцы и интерпретация

Служебные столбцы с временем, хешами, адресами файлов/реестров и постоянными значениями исключены. Простая загрузка заменена полным циклом Fidesys. Добавлены живость, экспортные статусы и счётчики, сообщения по этапам, сравнение исходного/экспортированного JSON. Имя кейса и JSON-пути находок сохранены. Ссылки на пункты спецификации внутри описаний остаются доказательствами; полные пути исходников/логов отдельными колонками больше не представлены. Хеши и сведения о происхождении хранятся в служебных реестрах.

После `Fidesys_загружено_элементов` добавлен `Fidesys_разница_с_числами_JSON`. Он сравнивает контрольные счётчики API с явно заданными `mesh.nodes_count` и `mesh.elems_count` исходного файла:

- `Нет` — оба числа совпали.
- `Да; узлы: JSON=…, Fidesys=…; элементы: …` — указаны несовпавшие числа.
- `Неизвестно; нет данных: …` — нет необходимых счётчиков; отсутствие данных не заменяется нулём или совпадением.

Из всех вычисляемых предупреждений исключена только точная фраза `The distance between nodesets is not accurate` (с завершающей точкой или без неё). Она не влияет на текст, счётчики, статус и пояснение Fidesys. Фильтр применяется к обоим этапам; остальные предупреждения сохраняются. Исторические необработанные логи сохраняют исходный вывод. Для будущих запусков тот же фильтр действует в `work/fidesys_import_audit.py`.

Fidesys повторно запущен для каждого исходника с импортом и экспортом; fc-model roundtrip и аудит спецификации сохранены. Для всех файлов подтверждены исходные SHA-256. Суммарный счётчик API снимается после экспорта; без экспортного маркера остаётся пустым. Счётчик ошибок API может отличаться от числа уникальных сообщений. У незавершённых импортов неизвестные счётчики пустые, измеренные нули остаются нулями.

## Сборка и проверка

`build.mjs` собирает матрицу через `@oai/artifact-tool`, проверяет ячейки и сохраняет их как CSV. Нужен Node.js с доступным пакетом через `node_modules`. Источники: JSON-cleanup roundtrip, новый `fidesys_roundtrip/results.json`, текущий `spec_audit/results.json`. Старый реестр простой загрузки больше не используется.

Текущая независимая проверка: `../1_2_2026-09-11_fidesys_roundtrip/verify.py` и `verification.json`. Проверены все 1130 строк/логов/исходников, хеши экспортов, новые статусы и счётчики, сохранность прежних колонок fc-model/спецификации. Все 450 живых моделей сохраняют число узлов/элементов от исходника через импорт до экспорта. Подробный отчёт, `alive_files.txt`, `alive_manifest.json` и каталог `exported/` находятся рядом с verifier.

`Fidesys_живая_модель=Да` обозначает подтверждённый безошибочный цикл. По решению пользователя эта модель считается актуальной; legacy/нарушения спецификации остаются наблюдениями для калибровки. `Fidesys_выход_FC_валиден` означает строго читаемый JSON с header/mesh и корректными счётчиками, а не полную валидацию физики/спецификации. Само создание такого файла после ошибочного импорта не подтверждает живость. `Fidesys_экспорт_завершён` фиксирует маркер завершения команды, а не отсутствие её ошибок.

`verification.json` в этом каталоге — квитанция текущего builder. Квитанции в spec_audit и spec_corrections, а также `independent_verification.json` относятся к историческим версиям таблицы. Предыдущий verifier на 33 столбца проверяет прежнюю стадию; текущий — на 45 столбцов.

```bash
python work/1_2_2026-09-11_spec_audit/run_audit.py
node work/1_2_2026-09-11_test_summary/build.mjs
PYTHONPATH=src python work/1_2_2026-09-11_fidesys_roundtrip/verify.py
```

Уточнение пользователя о `property_id: -1`: отсутствие специальных свойств у не-балочного/не-оболочечного блока. Снято 238 прежних BLOCK.PROPERTY_SENTINEL в 151 файле; все остальные 5586 находок и все результаты roundtrip сохранены. Сверка: `work/1_2_2026-09-11_property_id_sentinel/verification.json`.
