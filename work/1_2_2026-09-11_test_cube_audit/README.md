## Дополнительная проверка сетки и условий

Куб занимает диапазон [-5,5] по каждой оси; 1331 уникальный узел, 1000 HEX8 с уникальными ID. Координаты конечны, все ссылки связности ведут на существующие узлы. Все элементы относятся к блоку 1, он ссылается на существующие материал 1 и систему координат 1. Нагрузка type 3 содержит 100 пар элемент/грань: ссылки на элементы и номера граней допустимы. Закрепление содержит 121 существующий узел. Длины массивов согласованы с JSON-счётчиками. Декодирование выполнено через публичный FCValue, справочник элементов взят из публичного API. Свидетельства — `mesh_verification.json`.

Границы вывода по спецификации: это проверка описанных требований и применённых правил, не формальное доказательство полноты документа и не расчёт решателем. Пользователь уточнил: `blocks[].property_id: -1` означает отсутствие специальных свойств у блока, который не является балочным/оболочечным. Для данного объёмного кубика это корректное значение; прежняя оговорка снята, смысл внесён в спецификацию. Также документ не задаёт полную схему обязательности всех показываемых полей; отсутствие показанного в примере header.types.FCTYPE само по себе здесь не объявлено нарушением.
