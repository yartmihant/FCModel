# Уточнение property_id = -1

Решение пользователя: блок не балочный/оболочечный и не имеет специальных свойств; -1 не является ссылкой на property_tables.

План: синхронизировать спецификацию и LLM-контекст, исправить правило аудитора, проверить -1/0/обычные ссылки, пересчитать аудит и CSV, проверить неизменность остальных находок и колонок. Все 238 прежних замечаний относятся к 151 файлу с обычными объёмными/плоскими FEM-элементами (TETRA, HEX, WEDGE, PYR, TRI, QUAD), не к балкам или оболочкам.

## Результат

План выполнен. В обеих копиях спецификации уточнён комментарий property_id на строке 1021 без сдвига других строк и смены окончаний строк. Обе копии LLM-контекста синхронизированы. Для -1/-1.0 больше не проверяется наличие таблицы; поведение 0 и других ссылок сохранено. Дополнительное правило допустимости специальных типов элементов не вводилось.

Снято ровно 238 замечаний в 151 файле, остальные 5586 находок побуквенно сохранены. Неясностей стало 4634; 780 нарушений и 172 legacy остались. Итоговые статусы файлов прежние: 491 с нарушениями, 454 с legacy/неясностями, 185 без находок. CSV сохраняет 1130 строк и 45 колонок; изменились только пять колонок со spec-находками. Все остальные ячейки совпадают с предыдущей версией, полные массивы находок сверены для всех строк. Хеши исходных FC подтверждены полным аудитором и сборщиком CSV.

Проверки: 30 тестов аудитора, Pyright двух изменённых Python-файлов — 0 ошибок. Штатный pytest — 194 passed / 2 прежних failed (test_load_apply_remapped, test_tetra4_properties). Аудитор и штатные тесты запускались раздельно, поскольку совместный запуск без importlib-режима конфликтует из-за одинаковых имён тестовых модулей. Сверка — verification.json; сохранены предыдущие spec-реестр и CSV для воспроизводимости. Повторная проверка кубика замечаний не нашла.

Fidesys, roundtrip библиотеки и решатель повторно не запускались. Изменено только определение и соответствующая оценка формата. Код пакета, исходные FC и VERSION сохранены. Существующие исторические протоколы прежних этапов не переписывались.
