# Согласованные поправки спецификации и CSV

Этот документ фиксирует предыдущую стадию на 33 столбца. Позднее простая загрузка заменена реальным Fidesys roundtrip; текущий отчёт и verifier находятся в `../1_2_2026-09-11_fidesys_roundtrip/`, текущий CSV содержит 45 столбцов.

## Что изменено

В `docs/FC_INPUT_FORMAT.md` и копии пакета приняты ровно пять решений пользователя:

1. `mesh.elem_types` содержит uint8, один байт на элемент независимо от header.types.int.
2. Output-настройки static/dynamic можно не задавать; несколько вариантов одновременно по-прежнему запрещены.
3. Число объектов группы материала не ограничено одним. Объект вместо массива остаётся отдельной нерешённой проблемой.
4. JSON int допускает целочисленные float; bool, дробные значения и NaN/Infinity не допускаются, диапазоны и enum сохраняются. Правило не меняет бинарные размеры.
5. Eigen solver использует `auto` вместо `Auto`.

Смысл текстов обеих копий совпадает. Сохранены исходные окончания строк (CRLF в docs, LF в копии пакета) и прежние номера строк, чтобы ссылки аудитора остались действительными. Соответствующее уточнение внесено в обе копии LLM-контекста. Ранее известная устаревшая версия 1.2.0 в LLM-контексте не исправлялась в рамках этой задачи; текущий VERSION — 1.2.8.

## Аудит

Все четыре области повторно выполнены для всех 1130 исходников. DOC.DIMENSIONS_CONFLICT и MESH.BINARY_SEMANTICS_UNCHECKED больше не создают находок файлов; ограничения сохраняются в документах охвата. Никакие иные неясности не разрешены автоматически.

Сравнение с git-снимком `4bd5f2284613be67284c238e595ea37b66db3ee6` подтвердило отсутствие новых/изменённых находок и сохранение всех **5824** оставшихся записей. Сняты только:

- 593 MESH.ARRAY_SIZE и 516 MESH.BUFFER_SIZE для elem_types;
- 781 SET.EXCLUSIVE при отсутствии всех output-вариантов;
- 396 отдельных MAT.GROUP_CARDINALITY;
- 307 PT.PROPERTY_FIELD для целочисленных float;
- одна DOC.FIELD_TYPE для eigen_solver.number=10.0;
- 84 SET.ENUM для solver=auto;
- 1130 DOC.DIMENSIONS_CONFLICT и 1118 MESH.BINARY_SEMANTICS_UNCHECKED.

Текущая классификация: **491 файл с нарушениями, 454 только с legacy/неясностями, 185 без находок по выполненным правилам**. Счётчики находок: 780 violation, 172 legacy, 4872 ambiguity. Это не заключение о физической корректности модели или работе решателя.

## CSV и Fidesys

В прежнем файле `../1_2_2026-09-11_test_summary.csv` теперь 1130 строк и 33 столбца: удалены 18 служебных/постоянных столбцов, добавлена одна колонка сравнения сетки. Имена файлов и JSON-пути сохранены; адреса файлов, хеши и времена остаются в служебных реестрах.

`Fidesys_разница_с_числами_JSON` стоит сразу после загруженных элементов. Она сравнивает обе величины с явно записанными mesh.nodes_count/elems_count, сообщает несовпавшие значения и отличает неизвестный результат от нулевого счётчика: **1097 совпадений, 31 расхождение, 2 неизвестных**. Все 31 расхождение относятся к импортам с ошибкой; их список находится в `verification.json`, поле mismatch_files.

Только предупреждение `The distance between nodesets is not accurate` исключено из текста, счётчика, статуса и пояснения Fidesys, а также из парсера будущих запусков (допускается завершающая точка). Изменение затронуло 315 файлов. Другие предупреждения сохранены в 52 файлах; все они имеют ошибки импорта. **450 успешных импортов теперь не имеют учитываемых предупреждений**.

Исходные логи и исторические реестры Fidesys сохраняют исходные сообщения; это доказательства запусков, не текущая аналитическая классификация. Независимая проверка заново разобрала все 1130 логов новым фильтром и подтвердила сохранность ошибок/счётчиков. Новых запусков Fidesys и roundtrip не было; для каждого исходника сверены хеши. Roundtrip: прежние 453 совпадения, 611 расхождений, 66 исключений; Fidesys: 450 без ошибок, 678 с ошибками, 2 незавершённых.

## Проверки

- 43 целевых теста правил и фильтра: пройдены. Проверены как разрешённые варианты, так и остающиеся ошибки; успешные fixtures всех областей проверены с целочисленными float.
- Pyright изменённых инструментов и независимого verifier: 0 ошибок.
- Штатный pytest: прежние 194 passed / 2 failed (`test_load_apply_remapped`, `test_tetra4_properties`). Штатный Pyright: прежние 19 ошибок в тестах; код пакета не менялся.
- Независимый CSV-парсер: 1130 уникальных строк, 33 колонки, сохранность оставшихся старых аналитических полей, точные счётчики/содержимое находок, отсутствие постоянных колонок, корректность сравнения размеров и фильтра предупреждений. SHA-256 исходников и текущих правил совпадают с реестрами.
- Просмотрены PNG-предпросмотры новых столбцов сетки и изменённых статусов спецификации: заголовки и значения читаются. Матрица проведена через Artifact Tool с проверкой значений каждой ячейки.

Команды сборки приведены в README каталогов spec_audit и test_summary. Код библиотеки, корпус и VERSION не менялись; git-команды изменения не выполнялись.
