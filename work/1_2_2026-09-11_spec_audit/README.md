# Аудит 1130 файлов по спецификации FC

Текущие результаты пересчитаны после пяти поправок, утверждённых пользователем 2026-09-11, и внесены в `../1_2_2026-09-11_test_summary.csv` (1130 строк; после добавления Fidesys roundtrip — 45 столбцов). `results.json` содержит текущий полный реестр. Исторические 1129 файлов с violation относились к прежним правилам; подробный разбор причин — `../1_2_2026-09-11_spec_findings_review_report.md`.

Живость теперь определяется отдельным Fidesys roundtrip: успешный импорт и экспорт признаются пользователем свидетельством актуальности модели. Spec-находки остаются материалом для калибровки и не отменяют этот статус. Текущая сверка CSV — `../1_2_2026-09-11_fidesys_roundtrip/verify.py`.

## Принятые правила

1. Бинарный `mesh.elem_types` — uint8, один байт на элемент независимо от header.types.int.
2. Output-настройки static/dynamic опциональны. Одновременно допускается не более одного варианта; другие условия timestep не изменены.
3. Группа материала может содержать несколько объектов; каждый проверяется по своей схеме. Объект вместо массива по-прежнему отмечается.
4. JSON int допускает целочисленный float. Bool, дробные и нечисловые значения не становятся целыми; диапазоны и enum сохраняются.
5. Eigen solver использует `auto`, а не `Auto`.

По указанию пользователя DOC.DIMENSIONS_CONFLICT и MESH.BINARY_SEMANTICS_UNCHECKED исключены из находок файлов. Ограничения охвата описаны в сопровождающих документах. Остальные вопросы, включая null, layers, остальные sentinel, дубликаты ID и damping, не переопределялись.

## Метод и границы

Все четыре модуля выполняются на каждом исходнике независимо от FCModel и Fidesys. Исходные правила трёх областей подготовлены Luna и проверены основным агентом; header/settings и интеграция выполнены основным агентом. Эта работа исправляет правила и повторно запускает аудит; нового ручного чтения всех файлов субагентами не заявляется. `review_*.json` — исторические выборочные протоколы первоначального этапа, а не актуальная классификация после поправок.

`run_audit.py` проверяет UTF-8/JSON, запрещает NaN/Infinity и повторные JSON-ключи, запускает document/mesh/materials/conditions, считает все категории и сохраняет SHA-256 исходников, спецификации и инструментов. Сверка исходников идёт с реестром roundtrip, поэтому удаление SHA256 из CSV не ломает повторный запуск.

- `violation` — расхождение с применённым требованием документа; оно не доказывает отказ Fidesys.
- `legacy` — описанная устаревшая структура.
- `ambiguity` — неизвестные поля/коды или неразрешённые вопросы формата.
- `check_error` — внутренний сбой проверки; публикация такого прогона завершается ошибкой.

Ни успех roundtrip, ни импорт без ошибок не заменяют проверку документа. Сам документ также не является полной формальной схемой. Полная семантика бинарных ссылок, topology/face соответствие, геометрическая/физическая корректность и работа решателя не проверяются. Охват и оставшиеся ограничения: `coverage_document.md`, `coverage_mesh.md`, `coverage_materials.md`, `coverage_conditions.md`. Контракт — `CONTRACT.md`.
