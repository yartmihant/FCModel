# Согласованные поправки спецификации и сводного CSV

## Контекст и цель

Пользователь утвердил пять поправок: uint8 elem_types, опциональные output-настройки, отсутствие лимита объектов в группе материала, целочисленные float для int и solver=auto. Остальные вопросы остаются предметом исследования. Требуется пересчитать аудит всех 1130 файлов и упростить существующий CSV.

## Источники истины

Решение пользователя → docs/FC_INPUT_FORMAT.md и синхронная копия пакета → аудиторы. Реестры предыдущего roundtrip/Fidesys и исходные JSON служат доказательствами; актуальность проверяется по SHA-256.

## Изменения

Пять поправок в обеих спецификациях; правила и тесты аудитора; фильтр одного предупреждения в разборе Fidesys и сборщике CSV; сравнение API nodes/elements с mesh.nodes_count/elems_count; удаление служебных и постоянных столбцов. Два глобальных замечания не включаются в находки файлов. Исторические логи сохраняют исходные сообщения, но анализ их игнорирует. Код пакета и корпус не меняются.

## План и проверки

1. Обновить спецификацию без смещения прежних номеров строк и синхронизировать копию.
2. Исправить правила, проверить разрешённые варианты и сохранение запретов на недопустимые данные.
3. Перезапустить аудит на всех файлах. Сверить удалённые находки с перечнем утверждённых причин, сохранить остальные.
4. Пересобрать CSV через существующий Artifact Tool builder; проверить все строки независимым CSV-парсером, предупреждения и сравнения сеток, выполнить визуальную проверку новых столбцов.
5. Выполнить целевые/штатные тесты и типизацию, обновить сопровождающие документы и CHANGELOG.

## Вопросы и риски

Блокирующих вопросов нет: проектные решения уже даны пользователем. Если нет маркера завершения импорта, сравнение размеров обозначается как неизвестное, а не совпадение. Импорт с ошибкой может иметь корректные счётчики сетки — это независимые результаты. Исторические отчёты остаются снимками прежних правил. Изменения не подтверждают корректность расчёта решателем.
