## Проверка кодирования по библиотеке

По указанию пользователя исследованы FCMaterial, FCData, FCValue, FCModel.save и общие циклы компонент loads/restraints/initial_sets. В Python-библиотеке constants — JSON-массив строк по свойствам, числовой payload каждого свойства кодируется отдельно; таблица имеет список кодов зависимостей и список отдельно кодированных столбцов аргументов. Метаданные остаются JSON-массивами. Поэтому прежний вопрос об упаковке закрыт для fc_model: исправлены две схемы полей и два примера материалов, полученные через публичный API. Исходники C++ FCParser.cpp в этой проверке не использовались.

Команда `python -m pytest tests/test_materials.py tests/test_data.py tests/test_value.py -q`: 40 passed. Дополнительно выполнены JSON-roundtrip для констант, таблицы и формулы. Представление примеров в документации проверяется декодированием через FCMaterial.
