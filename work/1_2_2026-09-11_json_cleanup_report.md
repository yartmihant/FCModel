# Исправление трёх синтаксически некорректных JSON

По прямому указанию пользователя «почини их или удали» исправлены два файла,
третий удалён из `data/fc_core_tests`.

## Изменения

- `Contact2dQuad8_CGS1_regular_notconform_nogap_tension_PL.fc`: удалена одна
  лишняя запятая после объекта `settings.test_opts`.
- `Contact3dHex8_Tied_RBE2_findefs_Penalty.fc`: удалена одна лишняя запятая
  после `contact_constraints[0].tangent_stiffness`.
- `EfPrCond_OrthogReinforced_Tet10_per.fc`: удалён. Файл оборван внутри
  Base64-строки `mesh.nodes`; утрачены часть координат и последующее содержимое.
  Достоверно восстановить его нельзя: найденный вариант `Tet10s3` содержит
  другие ID узлов и координаты, а единственная версия файла в git уже оборвана
  и имеет ту же SHA-256. Недостающие данные не подменялись предположениями.

В каждом исправленном файле удалён ровно один байт — запятая. Остальные байты,
включая CRLF и бинарные поля, сохранены. Все остальные файлы корпуса имеют
прежние SHA-256. [Манифест действий и хешей](1_2_2026-09-11_json_cleanup/changes.json).

## Проверки

Строгий разбор всех **1130** оставшихся `.fc` выполнен успешно: нет ошибок
JSON, повторных ключей и NaN/Infinity.

Повторный полный roundtrip через `FCModel.load()` → `save()`:

- **453** совпадают (было 451).
- **611** имеют расхождения (без изменения).
- **66** завершаются ошибкой загрузки модели (исключая устранённые ошибки JSON).

Оба исправленных файла теперь проходят roundtrip точно. Новый актуальный
[реестр roundtrip](1_2_2026-09-11_json_cleanup/roundtrip_results.json);
выходные модели сохранены в `/tmp/fc_core_roundtrip_json_cleanup_2026-09-11`.

Повторный импорт двух исправленных исходников в препроцессор Fidesys 8.1
подтвердил устранение синтаксической проблемы, но сохранил прежние ошибки модели:

- `Contact2dQuad8_CGS1_regular_notconform_nogap_tension_PL.fc`:
  `Unrecognized Identifier: 'pure_lagrangian'` и ошибка внутренней команды.
- `Contact3dHex8_Tied_RBE2_findefs_Penalty.fc`: `Invalid element id 3.`

[Результаты и пути к полным логам](1_2_2026-09-11_json_cleanup/fidesys/results.json).
Оба импорта достигли контрольного маркера; процессы завершены. Исправления
касаются JSON-синтаксиса, а не других ошибок препроцессора. Два случая раннего
завершения (`Contact2dQUAD9.fc`, `Contact3dHEX27.fc`) не изменялись.

Штатный pytest: **194 passed / 2 failed**, прежние
`test_load_apply_remapped` и `test_tetra4_properties`.
[Лог](1_2_2026-09-11_json_cleanup/pytest.log).
Код библиотеки и Python-тесты не менялись, новая проверка типов не требуется.
Источники: правила AGENTS.md, JSON/UTF-8 контракт спецификации,
API-индекс и результаты предыдущих проверок.

## История результатов

Предыдущие JSON-реестры и отчёты сохраняют снимок корпуса **до** исправлений:
1131 файл и три ошибки JSON. Их SHA-256 для двух изменённых файлов уже
не соответствуют текущему корпусу, а удалённый файл отсутствует. Для новых
импорт-проверок следует передавать актуальную baseline:

```bash
PYTHONPATH=src:work python work/fidesys_import_audit.py \
  --baseline work/1_2_2026-09-11_json_cleanup/roundtrip_results.json \
  --output work/1_2_2026-09-11_fidesys_import_next --workers 8
```

Спецификация, публичный API, VERSION и git-история не менялись.
Действия и результаты записаны в `[Unreleased]` CHANGELOG.
