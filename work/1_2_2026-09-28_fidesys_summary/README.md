# Отдельная таблица Fidesys roundtrip

## Задача и план

Создать отдельный CSV для 1130 кейсов корпуса, используя сохранённый прогон Fidesys от 2026-09-11. Полностью исключить settings, header и имена сущностей из сравнения. Старый сводный CSV не менять.

1. Проверить хеши исходников и экспортов; заново сравнить JSON после удаления исключённых полей.
2. Проверить компаратор на исключённых полях и значимых изменениях.
3. Собрать только результаты Fidesys, сообщения и учитываемые различия, без fc-model/spec-колонок и служебных адресов/хешей/времени.
4. Сверить все CSV-строки с результатами сравнения, проверить читаемость, записать итог в CHANGELOG.

## Критерий

«Пройден»: импорт и экспорт завершены без ошибок, выходной FC корректен и JSON совпадает с исходным после исключений. Отдельная колонка JSON показывает сравнение также для частичных экспортов после ошибки импорта.

Исключаются корневые settings и header целиком, а также name непосредственно у записей blocks, materials, property_tables, coordinate_systems, loads, restraints, initial_sets, contact_constraints, coupling_constraints, periodic_constraints, receivers, orientations, imported_sections, legacy contacts/bcs/load_sets/restraint_sets и у nodesets/sidesets внутри sets. Не исключается произвольный вложенный ключ name: например, имя алгоритма внутри значимого объекта может менять его смысл.

Порядок ключей объектов не учитывается. Наличие остальных полей, числовые типы, значения, порядок/длина массивов и строки Base64 сравниваются строго. Сортировка/перенумерация узлов и элементов, эквивалентность формул и числовые допуски не применяются.

Предупреждение `The distance between nodesets is not accurate` по прежнему решению пользователя исключается; прочие предупреждения сохраняются и сами по себе не означают отказ. Нулевое число различий у совпавшего JSON отличается от пустой ячейки, когда сравнение невозможно.

## Источники и границы

Источник: work/1_2_2026-09-11_fidesys_roundtrip/results.json и его exported/. Файлы сравниваются с data/fc_core_tests/. test_cube.fc находится вне этого корпуса и в 1130 строк не включён. Реальный новый прогон Fidesys не выполняется; меняется критерий оценки сохранённых результатов. Код библиотеки, спецификация и исходные модели не меняются.

## Результат и проверки

Создан `../1_2_2026-09-28_fidesys_roundtrip.csv`: 1130 строк, 22 столбца, UTF-8 с BOM, запятая, RFC 4180. Пройдено 32, расхождения после завершённого цикла без ошибок у 418, ошибки импорта у 678, незавершённый импорт у 2. Независимый JSON-статус: 32 совпадения, 1065 различий (включая частичные экспорты после ошибки), 31 некорректный выход, 2 отсутствующих экспорта.

CSV содержит статусы, число/разделы/пути/описания и JSON учитываемых различий, сообщения импорта/экспорта, счётчики узлов и элементов входа/импорта/выхода и их сопоставление. У исключённых полей нет даже справочных diff-колонок. Большие значения в различиях представлены префиксом и длиной, контейнеры — типом/размером; сравнение выполняется по полным значениям. Технические хеши сохранены только в results.json/verification.json, не в CSV.

Проверены 1130 исходных хешей и 1128 выходных хешей. Все 1097 доступных пар JSON независимо сравнены через каноническую сериализацию после удаления разрешённых полей. Все 1130 CSV-строк проверены; старый сводный CSV сохранил SHA-256. Данные проведены через Artifact Tool, просмотрены четыре характерных результата. Три теста компаратора проходят (включая порядок массивов, числовые типы, вложенный значимый name, отсутствующие fields и немутируемость исходника); Pyright новых Python-файлов без ошибок. Штатный pytest сохраняет 194 passed / 2 прежних failed (`test_load_apply_remapped`, `test_tetra4_properties`).

Воспроизведение из корня проекта:

```bash
PYTHONPATH=src:work python3 work/1_2_2026-09-28_fidesys_summary/compare.py
node work/1_2_2026-09-28_fidesys_summary/build.mjs
python3 work/1_2_2026-09-28_fidesys_summary/verify.py
```

Для builder нужен @oai/artifact-tool из зависимости runtime, подключённый symlink node_modules; зависимость не хранится в репозитории. Удаление пользователем lock-файла старого CSV сохранено. VERSION не изменён, запись добавлена в CHANGELOG 1.2.10 [Unreleased].
